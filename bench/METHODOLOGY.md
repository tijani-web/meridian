# bench/METHODOLOGY.md — Benchmark Methodology

All benchmark numbers in README and docs trace back to committed runs here.
Per §1.2: never claim a number without a committed measurement behind it.

---

## Hardware and Environment (Committed Runs: 2026-10-28)

- Host OS: Windows 11 Enterprise (64-bit)
- Go: go version go1.24.0 windows/amd64
- Kubernetes: kind v0.29.0, node image kindest/node:v1.33.1
- Fleet Simulation: KWOK v0.6.0 simulated nodes
- Simulated Node Configurations:
  - 500 nodes (4,000 GPUs) and 2,000 nodes (16,000 GPUs)
  - 8 GPUs per node (75% NVIDIA H100 SXM5 80GB, 25% NVIDIA A100 80GB)
  - Interconnect topology: 8 nodes per NVLink domain, 32 nodes per rack, multi-zone
- Synthetic Workloads: `tools/trace-gen` Poisson arrivals, 1/2/4/8 GPUs per replica, gang size 1-16 pods (total 1-64 GPUs), 3 fair-share queues, 3 priority tiers

## Reproducibility

Every benchmark run stores results in `bench/results/<date>-<name>/`:
- `raw/`: raw CSV or JSON output from the workload generator
- `params.json`: all parameters (node count, job mix, seed, repetitions)
- `stdout.log`: full tool output
- `run.sh`: exact command that produced the results (can be re-run to reproduce)

Plots are generated by `bench/scripts/plot-results.sh` from committed raw data.

## Statistical Rigor

- Minimum **5 repetitions** per measurement.
- Report: **median** as the primary metric, **p5 and p95** as spread.
- Warm-up: discard the first run (JIT/cache cold start effects).
- Fixed random seed documented in `params.json` for reproducibility.

## Simulated vs Real

All scale benchmarks (Phase 08) use **KWOK simulated nodes**.
Every plot and table produced from KWOK data is labeled **"[simulated fleet]"**.
If a real-GPU run is conducted (Phase 10 §8.3), those results are stored in a
separate `bench/results/<date>-<name>-real-gpu/` directory and labeled **"[real GPU]"**.

## Comparison Baselines

- **Scheduler benchmark**: compare Meridian vs default kube-scheduler vs
  (if installable) Kueue + default scheduler.
- **Router benchmark**: compare all four strategies
  (RoundRobin, LeastQueue, KVAware, PrefixAffinity).

If a baseline cannot be installed in the environment, it is stated explicitly in
the results README and in `docs/LIMITATIONS.md`.
